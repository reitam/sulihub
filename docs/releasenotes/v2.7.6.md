## Változások

### #158 – Desktop esemény-tábla

- A #153 mobil nézet markupja (`.mobile-datum`, `.mobile-jegy-hely`) desktopon is
  megjelent, ezért a Tantárgy oszlopban összefűzve látszott a rövid dátum
  (pl. „Irodalom11.20.”), az értékeléseknél pedig a jegykör is.
- Javítás: a mobil elemek alapból `display: none`; a mobil media queryben kapnak
  `inline` / `inline-flex` értéket. Desktopon a Tantárgy cella csak a tantárgyat
  mutatja, a dátum és a jegy a saját oszlopában marad.
- Regressziós teszt: `test_dashboard.py` 3. szakasz (desktopon a mobil dátum/jegy
  `display: none`); `test_mobile_layout.py` továbbra is zöld.

### CI-stabilitás

- A scheduled browser futás a `test_dashboard.py` kalkulátor-szakaszán bukott,
  mert 900 ms után még „Számolás…” állapotot látott. A teszt most
  `wait_for_function`-nel vár a tényleges eredményre (max. 10 s).

### #157 – Repository átnevezés

- GitHub: `reitam/kreta_adatlekero` → **`reitam/sulihub`**; a régi URL átirányít.
- A helyi remote, a README clone URL-je és a dokumentáció hivatkozása frissítve;
  a megosztott felhasználók értesítése GitHub issue-ban történt.
- Ez nem érinti a futó alkalmazást; a helyi mappa továbbra is
  `C:\sulihub`, a konténer/image név `kreta-app`.
