## Változások

Docker-élesítés, mentés, alapfunkciók

Csatolmány-link javítás: relatív út a DB-ben, minden történeti formátum támogatva

A KRETA_CSATOLMANYOK_DIR=/app/data/csatolmanyok bevezetése után a scraper
ABSZOLÚT utat írt volna a DB-be, a frontend linkje pedig //app/... protokoll-
relatív URL-ként halott lett volna, a route safe_join-nal 404-et adott volna.

- scraper: os.path.relpath(save_path, CSATOLMANYOK_DIR) -> tiszta
  "diak_nev/fajl.pdf" a DB-ben (lokálisan és konténerben is ez a kanonikus)
- frontend: normalizálás minden történeti formátumra (static/csatolmanyok/,
  /app/data/csatolmanyok/, tiszta relatív) + route prefix + encodeURI
- backend route: ugyanaz a normalizálás védelemként (safe_join intact)
