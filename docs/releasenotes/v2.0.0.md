## Változások

**KRÉ-14 monolit-bontás, viselkedésváltozás nélkül.** `app.py` 4 107 → ~1 180 sor: a DB-réteg (`kreta_db`), az útvonalak (`kreta_paths`), a beállítások (`kreta_settings`) és a közös nézet-segédek (`views_common`) kiemelve; a HTTP-réteg **8 prefix nélküli blueprintbe** (`views_pages/events/orarend/messages/absences/stats/rewards`, `kreta_exports`), a stateful mag (sync/ütemező/ntfy/napló) szándékosan az `app.py`-ban maradt (a tesztek monkeypatch-elik). A frontend inline scriptje `static/js/core.js` + `static/js/app-main.js` alá került (`?v=` cache-busttal). **Futásidejű adatok `data/` alá** (DB, config, napló, tokenek, böngészőprofil, csatolmányok) legacy-fallbackkel és `tools/migrate_local_data.py` migráló/rollback szkripttel. **Az audit után javítva:** a tanév-szűrős súlyozott átlag (F1), a `data/` auto-létrehozás (F2), a Docker-füstteszt teljes modulgráfja (F3). **Új őrök:** `tests/test_routes_contract.py` (42 rule rule+metódus rögzítése), `tools/api_snapshot.py` (17 végpont válasz-diff), `tests/test_data_dir.py` (útvonal-feloldás + migráció). **1177 ellenőrzés / 39 csomag** (fast 34/1025, browser 5/152)
